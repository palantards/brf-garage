The current flow for residents is:
They go into the BRF homepage (a web hotel) which has a contact form for parking (garage),
which sends an email to garage@brfkrickan.se

The admin currently has track on queue for free spots, queue for applications, queue for EV spots.
Also has price for each spot.

Wishes for spots shouldn't be supported - the resident should be able to choose spot form tho, e.g. normal, MC or EV.

Since the app should be only for admins - instead flow would be that the admin answers the resident's email with a form that creates an application for a spot. The form should take some input like when (asap or from date). Perhaps show the map somehow?

Side note: Email etc. should be tracked from beginning to the end as well.

Resignation is also by email and should follow a similar flow, especially since it has a 3 month resignation time.

There is also a special type of deal/agreement, "Temporary" which has one month resignation time.

The whole thing should be more lika a CRM.

Basically CRM. Avtalstyp (stora platser, små, el, tillfälliga (1 mån))
